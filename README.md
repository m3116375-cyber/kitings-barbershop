# Kiting's Barbershop — Sistem Booking & Penjualan Layanan (Laravel 12)

Aplikasi web untuk booking layanan barbershop, pemilihan produk perawatan, dan pembayaran
(payment gateway **Midtrans** atau **COD**), dengan tiga peran: **Admin**, **Owner**, dan **Pelanggan**.

➡ **Mulai dari file [`PANDUAN_SETUP.md`](PANDUAN_SETUP.md)** — berisi langkah instalasi,
akun contoh, dan cara menghubungkan Midtrans.
